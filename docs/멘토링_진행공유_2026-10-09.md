# MuJoCo·VLM 연결 진행 공유

- 작성일: 2026-10-09
- 담당: 강영한 (CV)
- 목표: MuJoCo에서 만든 가상 CCTV 이미지를 GPU 서버의 Florence-2에 입력해 작업자 탐지 흐름을 확인

## 완료한 내용

1. 맥북에서 MuJoCo 3.15.0 뷰어를 실행하고, 바닥·금지구역 표시·작업자 모형·CCTV 카메라가 포함된 장면을 구성했습니다.
2. 작업자 모형을 금지구역 바깥과 안쪽에 각각 배치해 640×480 PNG 이미지 두 장을 추출했습니다.
3. 이미지를 GPU 서버 로그인 계정으로 전송하고, DIS06의 NVIDIA RTX A6000 48GB에서 Florence-2-base 추론을 실행했습니다.
4. 두 이미지 모두에서 Florence-2가 `person`을 검출하고 바운딩 박스를 반환했습니다. 검출 결과를 이미지에 그려 확인했습니다.

## 실행 환경

| 항목 | 확인값 |
|---|---|
| GPU 노드 | DIS06 |
| GPU | NVIDIA RTX A6000, 49,140 MiB VRAM |
| 드라이버 | 525.105.17 |
| Python | 3.13.9 |
| PyTorch | 2.10.0+cu128, CUDA 사용 가능 확인 |
| Transformers | 4.49.0 (별도 `florence2` 가상환경) |
| 모델 | `microsoft/Florence-2-base` |
| 입력 이미지 | MuJoCo CCTV 시점, 640×480 |

계산 노드에서 외부 DNS 조회가 되지 않아 패키지와 모델 파일을 로그인 서버에서 내려받아 공유 홈을 통해 사용했습니다. 모델 파일은 약 930MB입니다. Florence 가상환경은 기본 Conda 패키지를 공유하는 방식으로 만들었으며 설치 중 기존 `lerobot`과 Hugging Face Hub 버전 경고가 있었습니다. 기본 환경 자체는 변경하지 않았습니다.

## 탐지 결과

| 입력 | 정답 장면 | 모델 결과 | 바운딩 박스 (x1, y1, x2, y2; 픽셀) | 생성 시간 |
|---|---|---|---|---:|
| `cctv_1_outside.png` | 작업자 구역 밖 | `person` 1개 | (420.16, 141.84, 479.04, 240.72) | 약 14,152 ms |
| `cctv_1_inside.png` | 작업자 구역 안 | `person` 1개 | (292.16, 142.32, 349.76, 238.32) | 약 67.6 ms |

두 결과 이미지에서 초록색 바운딩 박스가 작업자 모형을 둘러싸는 것을 확인했습니다.

## 해석과 한계

- 확인된 것은 합성 이미지 두 장에서의 작업자 모형 탐지입니다. 실제 작업자 영상의 탐지 성능을 검증한 결과는 아닙니다.
- 첫 이미지와 두 번째 이미지의 생성 시간이 크게 다릅니다. 모델 첫 추론의 초기화·워밍업 영향이 포함됐을 수 있으므로, 이 수치만으로 KPI의 10Hz 달성 여부를 판정하지 않습니다. 반복 추론과 전체 입력·전처리·추론 파이프라인을 측정해야 합니다.
- 모델 출력에는 `person` 라벨과 픽셀 바운딩 박스가 있습니다. 온톨로지 `Observation`의 월드 위치, 신뢰도, 센서·시간 필드 변환은 아직 구현하지 않았습니다.
- `HazardEvent` 생성, 구역 침입 판정, 규칙 엔진 및 로봇 정지 연동도 아직 수행하지 않았습니다.
- 금지구역은 시각 표시일 뿐이며 MuJoCo 장면 자체가 침입을 판정하지 않습니다.
